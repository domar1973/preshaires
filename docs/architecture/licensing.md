# Licensing Notes

No `LICENSE`, `COPYING` or equivalent license file was found in this repository
during the bootstrap inspection.

The legacy `read.me` identifies MaGICS_TdF authorship and history, but it does
not state redistribution or reuse terms. Because of that, this bootstrap does
not add a new repository-wide license and does not move, delete or relicense
the legacy source.

Before publishing or redistributing preshaires, resolve:

- the intended license for new preshaires code;
- whether MaGICS_TdF legacy code can be redistributed under that license;
- whether Numerical Recipes-derived Fortran files in `src/NR` impose separate
  restrictions;
- whether `erber1966.pdf` may remain in the repository.
